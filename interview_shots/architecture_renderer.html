核心业务链路：
① 高并发抢位
Redisson 锁 → Redis+Lua 原子扣减（SHA1 预加载/懒加载/动态 TTL）→ MySQL 最终一致 → 2000 并发零冲突、无超卖
② 订单超时自动关单
下单发延迟消息 → TTL 到期 → 死信队列（DLX）→ 消费者幂等关单，名额自动释放
③ 关场次批量取消
店长关场次 → MQ 事件 → 批量取消该场未支付订单（SESSION_CLOSED）+ 名额回滚
④ AI 智能客服（跨语言）
玩家提问 → Java agent-gateway → Python LangGraph 意图识别 → 调内部接口 → 返回真实订单/剧本数据
⑤ 统一鉴权 / 配置 / 文档
Gateway JWT 全局鉴权 + @RequireRole 角色控制 · Nacos 统一配置 · Knife4j 接口文档 · 雪花 ID 订单号
